# Безопасность проекта «Вместе в путь»

Срез на 14.10.2026. Датированный аудит с наблюдениями, решениями и evidence
сохранён полностью в [архиве](history/security_audit.md). Здесь приведены
действующие меры и ограничения; новый ручной аудит в рамках редакции
документации не выполнялся.

## Реализованные меры

- Identity cookie, antiforgery для изменяющих запросов, lockout и rate limit.
- Проверка владельца всех поездок и вариантов; чужие идентификаторы дают 404.
- Конфликты revision дают 409, сохраняют черновик и требуют подтверждения
  перед отбрасыванием правок.
- Пользовательский ввод выводится текстом; ссылки допускают абсолютные
  HTTP/HTTPS и открываются с noopener noreferrer.
- Яндекс ID использует Authorization Code Flow с PKCE; токены и секреты
  остаются на backend. Метрика загружается только после явного согласия,
  пути очищаются, данные поездок сторонним сервисам не передаются.
- Секреты поступают из окружения или secret store; структурированные логи
  не содержат тела запросов и содержимого поездок.
- Контейнер работает без root, миграции выполняются отдельным заданием;
  PostgreSQL и ключи Data Protection сохраняются в постоянных volumes.
- CodeQL и аудит прямых/транзитивных NuGet-зависимостей блокируют публикацию.

## Проверки и ограничения

Результаты текущего CI, xUnit и smoke: [итоговый отчёт](../development_report.md).
OAuth в API-тестах использует тестовую схему; аналитика проверяется без отправки
реальных событий. Проверка публичного стенда выявила прежний интерфейс:
соответствие текущему коду и реальный OAuth-вход ещё нужно подтвердить.

Политика паролей допускает пять символов без требований к их классам.
Это сохранённое решение проекта и остаточный риск; lockout — пять ошибок
на пять минут. Принятие риска зафиксировано в
[SA-02](history/security_audit.md#sa-02--слабая-политика-новых-паролей).
DAST и penetration testing не выполнялись. Настройка required checks для merge,
ротация ранее раскрытых credentials и конфигурация production управляются
владельцем; их состояние в этой редакции не проверялось.
