# Документация «Вместе в путь»

Актуализация: 12 октября 2026 года. Документы описывают текущий код, включая
бюджетное дополнение в рабочем дереве; его production-выпуск не подтверждён.

| Документ | Назначение |

Инструкции эксплуатации сверяются с конфигурацией репозитория. Исторические
планы и исходное задание не переопределяют действующие требования.
