# Выполнение домашнего задания №4

> **Исторический документ.** Таблица ниже фиксирует завершение frontend-этапа ДЗ № 4.
> В ДЗ № 5 добавлены Identity, API, PostgreSQL, Docker Compose и GitHub Actions,
> а в ДЗ № 6 — OAuth 2.0, аналитика, security hardening и JSON-логи;
> текущее состояние описано в [корневом README](../../README.md) и
> [backend-документации](../../backend_documentation.md).

## Принятые решения

Пользователь выбрал **C# + Blazor WebAssembly + MudBlazor**.
Используются .NET SDK 10.0.303 и MudBlazor 9.7.0.

Основа — [существующее ТЗ](../technical_specification.md), обязательные истории US-01–US-10
и [концепция 3 «План поездки»](../ui_concepts/03-analytical.html).
Исходные документы проектирования сохранены как материалы ДЗ 3.

## Материалы ДЗ 2

В соседнем HT2 найдены Отчет/prompt_templates.md и Отчет/rules.md.
Структура RTCF адаптирована в [prompt_templates.md](prompt_templates.md),
рабочие правила — в [AGENTS.md](../../AGENTS.md).

На этапе ДЗ № 4 серверные EF Core/SQLite и Blazor Interactive Server не переносились.
В ДЗ № 5 добавлены Minimal API и EF Core с PostgreSQL, но не SQLite и не Interactive
Server. Node.js и npm для выбранного стека не требуются.

## Границы

Копирование вариантов, сортировка и отметка решения семьи не входят в обязательный MVP.
В ДЗ № 4 не было аккаунтов и серверного API; ДЗ № 5 добавляет их и синхронизацию
через PostgreSQL. Импорта цен по-прежнему нет.
